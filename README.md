# Image Processing & Sentiment Analysis using ML

Two machine-learning projects from the **Synapse** ML mentorship program.

![Python](https://img.shields.io/badge/Python-3776AB?logo=python&logoColor=white) ![OpenCV](https://img.shields.io/badge/OpenCV-5C3EE8?logo=opencv&logoColor=white) ![Jupyter](https://img.shields.io/badge/Jupyter-F37626?logo=jupyter&logoColor=white)

## 🖼️ Task 1: Image processing ([notebook](TASK-1-IMAGE%20PROCESSING/Synapse-task-1.ipynb))
Uses **OpenCV** to detect, analyze and segment geometric shapes in an image using **Canny edge detection** and **contour analysis**.

## 💬 Task 2: Sentiment analysis ([notebook](Task-2-NLP/Synapse_Task2.ipynb) · [synopsis](Task-2-NLP/Synapse-task-2-Synopsis.pdf))
An **NLP** pipeline that labels review text as **positive, neutral or negative**: NLTK stop-word removal, **CountVectorizer** bag-of-words, a **Multinomial Naive Bayes** classifier, and evaluation with accuracy and a confusion matrix.

## 🚀 Run
```bash
pip install jupyter opencv-python numpy pandas nltk scikit-learn
jupyter notebook
```
